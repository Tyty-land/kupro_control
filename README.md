# Родительский контроль

Курсовой проект по дисциплине "Технологии и методы программирования"

## Описание проекта

Система родительского контроля, состоящая из двух модулей:

### 1. Модуль "Ребенок" (ChildMonitor)
- Работает в фоновом режиме (system tray)
- Собирает информацию о запущенных процессах
- Принимает команды от родительского модуля
- Отображает уведомления

### 2. Модуль "Родитель" (ParentControl)
- Подключается к компьютеру ребенка
- Отображает активные процессы в реальном времени
- Отправляет текстовые сообщения
- Ведет учет времени использования приложений

## Технологии
- Язык программирования: C# (.NET Framework 4.8)
- UI: Windows Forms
- Сетевое взаимодействие: TCP/IP, JSON
- Логирование: NLog
